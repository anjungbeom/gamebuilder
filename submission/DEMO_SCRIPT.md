# 3분 데모 영상 대본

목표 길이: 2분 35초~2분 50초. 반드시 실제 플레이 화면을 녹화하고, 편집 후 3분을 넘지 않게 합니다.

## 00:00–00:15 — 한 문장 소개

화면: 타이틀에서 새 원정 시작.

내레이션: “Drawn Frontier는 그림으로 도구를 만들고 랜덤 맵을 개척하는 절차 생성 도트 탐험 게임입니다. 획의 길이, 꺾인 각도, 감싼 넓이, 갈래의 수가 그대로 장비 성능이 됩니다.”

## 00:15–00:45 — 핵심 독창성

화면: `Q` → 길고 뾰족한 한 획을 그린 뒤 실시간 파쇄력·사거리 변화 → 제작.

내레이션: “뾰족하면 바위를 깨고, 길면 멀리 닿습니다. 닫힌 면은 부력을 만들고 여러 획은 포획력을 높입니다. 지금 필요한 성능에 맞춰 도구를 직접 설계합니다.”

## 00:45–01:10 — 실제 개척

화면: 장애물에 접근 → 안내 확인 → Space로 제거 → 미니맵과 다음 신호기 방향 확인.

내레이션: “월드는 좌표와 시드로 생성됩니다. 각 지역의 우두머리를 쓰러뜨리고 다섯 신호기를 활성화하면 다음 지역이 차례로 열립니다.”

## 01:10–01:40 — 크리처와 성장 루프

화면: 붉은 `!` 적대 크리처와 전투 → P 패링 → 체력을 낮춘 뒤 F 포획 → 펫 합류. 이어서 민트 표식의 온순한 크리처를 보여줍니다.

내레이션: “적대 크리처는 약화시켜 포획하거나 처치할 수 있습니다. 첫 포획 크리처는 펫이 되어 주변 적을 함께 공격합니다. 온순한 크리처는 포획력이 충분하면 바로 길들일 수 있습니다.”

## 01:40–02:10 — 장비 가방과 선택

화면: `Tab` 장비 가방 → 신발 그리기 → 장착 → Shift 달리기와 신발 내구도 감소.

내레이션: “모은 잉크로 손도구와 신발, 펫 도구를 만듭니다. 손도구는 전투·채집·포획에 쓰이고, 신발은 달리기·안정성·내구도가 서로 달라집니다.”

## 02:10–02:35 — Codex 협업

화면: 저장소 모듈 구조, 테스트 성공 화면, GitHub Actions 성공 화면을 빠르게 교차.

내레이션: “Codex와 함께 기존 프로토타입을 모듈화하고 시스템을 하나의 성장 루프로 통합했습니다. 무작위 월드와 저장, 장비 제작, 브라우저 부팅까지 자동 테스트하며 Pages에 라이브 배포했습니다.”

## 02:35–02:50 — 마무리

화면: 신호기 활성화 효과와 새 지역이 열린 지도.

내레이션: “무엇을 그렸는지는 묻지 않습니다. 어떻게 생겼는지만 세계가 기억합니다. Drawn Frontier입니다.”

## 녹화 체크

- 1920×1080 또는 1280×720, 16:9
- 게임 사운드가 없으므로 내레이션 또는 저작권이 확보된 음악 사용
- 마우스 커서와 키 입력이 보이도록 편집
- 공개 또는 링크 공개 영상으로 업로드
- 업로드 후 URL을 `SUBMISSION.md`와 공식 폼에 입력
