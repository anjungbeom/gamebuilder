# 3분 데모 영상 대본

목표 길이: 2분 35초~2분 50초. 반드시 실제 플레이 화면을 녹화하고, 편집 후 3분을 넘지 않게 합니다.

## 00:00–00:15 — 한 문장 소개

화면: 타이틀에서 새 원정 시작.

내레이션: “Drawn Frontier는 길이 없으면 직접 그려서 여는 절차 생성 개척 게임입니다. 그림을 인식시키는 대신, 획의 생김새 자체가 장비 성능이 됩니다.”

## 00:15–00:45 — 핵심 독창성

화면: `Q` → 길고 뾰족한 한 획을 그린 뒤 실시간 바위·거리 수치 변화 → 제작.

내레이션: “뾰족하면 바위를 깨고, 길면 멀리 닿습니다. 닫힌 면은 물길을 건너고 여러 획은 포획에 유리합니다. 정답 그림을 맞히는 것이 아니라 지금 필요한 성질을 설계합니다.”

## 00:45–01:10 — 실제 개척

화면: 장애물에 접근 → 안내 확인 → Space로 제거 → 미니맵과 다음 맥점 방향 확인.

내레이션: “월드는 좌표와 시드로 무한 생성되고, 필요한 지형만 렌더링합니다. 다섯 개의 맥점을 연결하는 목표는 있지만 경로와 도구에는 정답이 없습니다.”

## 01:10–01:40 — 크리처와 성장 루프

화면: 붉은 `!` 적대종의 추격과 피격 → 포획 도구로 Space → 획 보상 표시. 이어서 민트 표식 평온종을 짧게 보여줍니다.

내레이션: “붉은 표식은 공격하는 위협종, 민트 표식은 도망치는 평온종입니다. 위협종을 포획하면 획 조각과 마일스톤이 쌓이고, 이미 처리한 개체는 다시 생성되지 않습니다.”

## 01:40–02:10 — 장비 팔레트와 트레이드오프

화면: `Tab` 팔레트 → 신발 그리기 → 장착 → Shift 달리기와 신발 내구도 감소.

내레이션: “모은 획은 장비 제작 비용입니다. 손도구는 지형과 포획에, 신발은 질주·안정·수명에 영향을 줍니다. 빠른 신발일수록 같은 재료에서 수명이 줄어 선택에 대가가 생깁니다.”

## 02:10–02:35 — Codex 협업

화면: 저장소 모듈 구조, 테스트 성공 화면, GitHub Actions 성공 화면을 빠르게 교차.

내레이션: “Codex와 함께 기존 프로토타입을 모듈화하고 시스템을 하나의 성장 루프로 통합했습니다. 무작위 월드와 저장, 장비 제작, 브라우저 부팅까지 자동 테스트하며 Pages에 라이브 배포했습니다.”

## 02:35–02:50 — 마무리

화면: 맥점 발견 빛 효과와 넓은 바이옴.

내레이션: “무엇을 그렸는지는 묻지 않습니다. 어떻게 생겼는지만 세계가 기억합니다. Drawn Frontier입니다.”

## 녹화 체크

- 1920×1080 또는 1280×720, 16:9
- 게임 사운드가 없으므로 내레이션 또는 저작권이 확보된 음악 사용
- 마우스 커서와 키 입력이 보이도록 편집
- 공개 또는 링크 공개 영상으로 업로드
- 업로드 후 URL을 `SUBMISSION.md`와 공식 폼에 입력
