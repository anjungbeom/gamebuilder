# 심사위원 퀵스타트

플레이: https://anjungbeom.github.io/gamebuilder/

설치·로그인·승인 없이 브라우저에서 바로 실행됩니다. 동일한 월드를 재현하려면 `?seed=1234`를 주소 뒤에 붙입니다.

## 조작

| 입력 | 기능 |
|---|---|
| WASD / 방향키 | 8방향 이동 |
| Shift | 달리기 |
| Q | 손도구 설계 |
| Space | 바라보는 방향의 장애물 제거·적대 크리처 공격 |
| P | 짧은 패링: 투사체 반사·근접 크리처 무장해제 |
| F | 약해진 적대 크리처 포획·온순한 크리처 길들이기 |
| Tab | 장비·수집품 인벤토리 |
| V | 다음 도전과제·해금 보상·완료 목록 |
| M | 확장 지도 |
| X | 해금 후 점프 |
| E | 해금 후 와이어 사용 |
| R | 해금 후 반사 방벽 사용 |
| C | 크리처 도감 |

## 3분 추천 플레이

1. 새 원정을 시작하고 미니맵의 가장 가까운 신호기 방향을 확인합니다.
2. `Q`를 눌러 길고 뾰족한 도구를 그립니다. 수치가 실시간으로 변합니다.
3. 가까운 바위·수풀에 다가가 Space로 길을 엽니다.
4. 붉은 `!` 적대 크리처와 민트색 온순한 크리처의 행동 차이를 확인합니다.
5. `Space`로 적대 크리처의 체력을 낮춘 뒤 `F`로 포획하거나, 끝까지 공격해 처치 보상을 얻습니다. 공격 직전 `P`를 누르면 근접 공격을 막거나 투사체를 되돌릴 수 있습니다.
6. `Tab`에서 신발을 그리고 장착한 뒤 Shift로 달립니다. 속도와 수명 트레이드오프가 적용됩니다.

상호작용에서 얻은 기술 조각은 탐사 등급을 올려 점프·와이어·반사 방벽을 해금합니다. `V`에는 바로 다음 목표 하나와 보상이 표시되고, 완료한 해금은 접힌 목록에서 확인할 수 있습니다. 수집품은 `Tab`에서 1개씩 버릴 수 있으며 10초 안에 다시 주울 수 있습니다. 마을에 들어가면 플레이어와 펫의 체력이 회복됩니다.

그림은 장착 칸에 따라 다르게 해석됩니다. 손도구는 파쇄형·장대형·방벽형·포획형·균형형 중 하나가 되며 충격·방어·조작·효율 보조 성능을 얻습니다. 신발은 달리기용 네 성능, 펫 도구는 공격력·지원거리·생존력·제압력으로 변환됩니다. 동행 중인 펫은 `Tab`에서 확인 후 방생할 수 있고, 제작한 펫 도구는 다음 펫을 위해 남습니다.

각 신호기는 연결 부위가 있는 우두머리가 지킵니다. 이동 봉인 → 투사 기관 → 기동 기관 순으로 빛나는 부위를 파괴하면 추적·사격·이동 보상함수가 차례로 제한되고, 완전히 제압된 뒤 표시된 방향에서만 본체 약점을 공격할 수 있습니다. 처치 시 연기와 함께 사라집니다.

낮밤과 날씨는 실제 대기 시간이 아니라 이동한 거리에 따라 진행됩니다. 달리기·공격·장애물 파괴는 소음을 높여 적대 크리처의 탐지 거리를 늘리고 온순한 크리처를 더 빨리 도망치게 합니다. 바이옴·날씨·낮밤에 따른 체온은 이동 속도에 영향을 줍니다. 잠긴 지역은 지도와 월드 모두 안개로 가려지며, 신호기를 활성화하면 빛기둥과 함께 다음 지역이 공개됩니다.

## 표식

- 붉은 원 + `!`: 플레이어를 추적하고 공격하는 적대 크리처
- 민트 원 + 작은 표식: 도망치며 길들일 수 있는 온순한 크리처
- 금색 사각 표식: 다음 지역의 신호기
- 민트빛 집과 다른 색 탐험가: 회복 마을과 주민
- 하트: 체력
- 도구/신발 숫자: 남은 내구도
- 잉크: 새 장비를 그릴 때 사용하는 제작 자원
