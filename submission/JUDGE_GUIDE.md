# 심사위원 퀵스타트

플레이: https://anjungbeom.github.io/gamebuilder/

설치·로그인·승인 없이 브라우저에서 바로 실행됩니다. 동일한 월드를 재현하려면 `?seed=1234`를 주소 뒤에 붙입니다.

## 조작

| 입력 | 기능 |
|---|---|
| WASD / 방향키 | 8방향 이동 |
| Shift | 달리기 |
| Q | 손도구 설계 |
| Space | 장애물 제거·크리처 포획/관찰 |
| Tab | 장비·수집 팔레트 |
| C | 생태 기록 |

## 3분 추천 플레이

1. 새 원정을 시작하고 미니맵의 가장 가까운 맥점 방향을 확인합니다.
2. `Q`를 눌러 길고 뾰족한 도구를 그립니다. 수치가 실시간으로 변합니다.
3. 가까운 바위·수풀에 다가가 Space로 길을 엽니다.
4. 붉은 `!` 위협종과 민트색 평온종의 행동 차이를 확인합니다.
5. 여러 획 도구로 포획 성능을 높여 위협종을 잡고 획 조각을 얻습니다.
6. `Tab`에서 신발을 그리고 장착한 뒤 Shift로 달립니다. 속도와 수명 트레이드오프가 적용됩니다.

## 표식

- 붉은 원 + `!`: 플레이어를 추적하고 접촉 피해를 주는 위협종
- 민트 원 + 작은 표식: 도망치며 관찰 보상을 주는 평온종
- 금색 사각 표식: 다음 개척 맥점
- 하트: 체력
- 도구/신발 숫자: 남은 내구도
- 획 조각: 새 장비를 그릴 때 사용하는 제작 자원
